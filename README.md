# Python Atlas — GitHub Pages

## Files
- `index.html` — main website page
- `style.css` — responsive dark theme styles
- `script.js` — topics, program search/categories, and copy-code actions
- `jagadish-photo.jpeg` — your contact/profile photo

## Upload to GitHub
1. Download and extract this ZIP.
2. Open your GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload all four files from this folder (not the folder itself).
5. Commit the changes.
6. In **Settings → Pages**, publish from your chosen branch and root folder if Pages is not already enabled.

The contact photo path is already set to `jagadish-photo.jpeg`. Keep that filename unchanged.
